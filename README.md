# 全球政经洞察总控台 · Global Geopolitical Hotspots Control Center

世界地图式全球政经洞察总控台：六方向（美国 / 欧洲 / 俄罗斯 / 中东中亚 / 亚洲 / 拉美）色块分区，23 个重点国点击查看政治体制、近期热点与既有洞察产品链接。

## 功能
- 太平洋居中版式世界地图（点击国家 = 洞察详情卡；悬停区域 = 区域热点；A−/A+ 界面字号控制）
- 洞察桥接：中美制裁与反制裁时间线 / 美国对华立法法案分析台 / AI 算力情报站 / 德国政党格局（持续接入中）

## 底图与边界数据声明
- 世界区域底图：Natural Earth（world-atlas 110m，公有领域）
- 中国全域（含台湾省、南海诸岛）边界画法：阿里云 DataV(GeoAtlas) 审图号 GS(2020)4393 号数据，符合中华人民共和国国界画法标准
- 裁切线位于大西洋西经 20°（太平洋居中版式）；俄罗斯、斐济跨 180° 经线已作连续性修正
- 本页面仅供内部研究使用，不作为行政区划依据

## 技术栈
单文件静态页（ECharts 5.5.1 离线内嵌 + 合成 GeoJSON），无后端、无外部依赖，由 GitHub Pages 托管。
